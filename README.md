# 1CCPG - Data Structures and Algorithms

## Descricao
Este repositorio contem os codigos, implementacoes praticas e exercicios desenvolvidos durante as aulas da disciplina de Data Structures and Algorithms (Estruturas de Dados e Algoritmos), ministrada no 1 ano do Bacharelado em Ciencia da Computacao da FIAP (Turma 1CCPG - 2026).

O objetivo central deste repositorio e consolidar o aprendizado sobre a organizacao eficiente de dados na memoria e a analise de complexidade de algoritmos. O dominio destes conceitos e fundamental para a construcao de software otimizado, escalavel e de alta performance.

## Tecnologias Utilizadas
- Linguagem C

## Estrutura do Repositorio
Os conteudos estao organizados modularmente, divididos pelos principais conceitos abordados ao longo do semestre:

- /Fundamentos: Alocacao dinamica de memoria e manipulacao de ponteiros.
- /Estruturas_Lineares: Implementacao de Arrays, Pilhas (Stacks), Filas (Queues) e Filas Circulares.
- /Listas_Encadeadas: Listas Simplesmente Encadeadas, Duplamente Encadeadas e Circulares.
- /Algoritmos_de_Ordenacao: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort e Quick Sort.
- /Algoritmos_de_Busca: Algoritmos de Busca Linear e Busca Binaria.
- /Estruturas_Nao_Lineares: Arvores Binarias, Arvores de Busca (BST) e nocoes de Grafos.

*Nota: O conteudo dos diretorios e atualizado progressivamente conforme o avanco das aulas e entregas de trabalhos.*
